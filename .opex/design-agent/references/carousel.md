# CAROUSEL STYLE GUIDE

Last updated: 2025-01-25
Version: 1

## SPECS

Resolution: 1080x1350px (4:5 ratio)
Slide count: 5-10 slides
Format: PNG
Background: #0A0A0A

## TYPOGRAPHY

Headline: Montserrat Bold, 48-64px, #FFFFFF
Body: Montserrat Regular, 24-32px, #FFFFFF
Secondary: Montserrat Regular, 18-24px, #A0A0A0
Accent: Montserrat Bold, 24-32px, #FF6500

## COLORS

Background: #0A0A0A
Card: #141414
Text: #FFFFFF
Secondary: #A0A0A0
Accent: #FF6500 (ONE element max per slide)

## SLIDE TYPES

Hook slide (slide 1):
  - Large centered text
  - Bold claim or question
  - No title, no decoration
  - Dark background only

Content slides (2-N):
  - One headline
  - 1-3 supporting lines
  - One visual element
  - Whitespace to breathe

CTA slide (final):
  - Clear action
  - Simple design
  - "Save this" or "Follow for more"

## QUALITY CHECKLIST

- [ ] Slide 1 hooks immediately
- [ ] Each slide has one idea
- [ ] Text readable at 375px width
- [ ] Accent used once per slide max
- [ ] Dark background on all slides
- [ ] Final slide has CTA
- [ ] Consistent spacing between slides
