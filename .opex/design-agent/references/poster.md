# POSTER STYLE GUIDE

Last updated: 2025-01-25
Version: 1

## SPECS

Resolution: 1080x1350px (portrait) or 1080x1080px (square)
Format: PNG
Background: #0A0A0A

## USE CASES

Event announcements
Product launches
Quote graphics
Stat/data highlights
Campaign visuals

## LAYOUT RULES

Center-aligned: for short, impactful messages
Left-aligned: for longer text content
Grid: for data or multiple elements

## TYPOGRAPHY

Headline: Montserrat Bold, 64-96px, #FFFFFF
Subheadline: Montserrat Regular, 32-48px, #A0A0A0
Stat: Montserrat Bold, 96-128px, #FF6500
Body: Montserrat Regular, 24-32px, #FFFFFF

## ELEMENT RULES

- Maximum 5 elements per poster
- One focal point (usually the headline or stat)
- Accent color for the focal point only
- Generous whitespace
- No cluttered backgrounds
