# SOCIAL POST GRAPHIC GUIDE

Last updated: 2025-01-25
Version: 1

## SPECS

Instagram square: 1080x1080px
Instagram portrait: 1080x1350px
Facebook: 1200x630px
LinkedIn: 1200x627px

## RULES

- Dark background always (#0A0A0A)
- Text must be readable at mobile size
- One accent color element max
- Minimal text — let the visual do the work
- Brand consistent across all platforms

## TEXT OVERLAY

For posts with text on image:
  Font: Montserrat Bold
  Size: large enough to read on mobile
  Color: #FFFFFF on dark background
  Max 10 words per overlay

## PHOTOGRAPHY

If using photos:
  - Dark filter or overlay
  - High contrast
  - Consistent color grading
  - No stock photo feel

## ICONS

Style: line icons, minimal
Color: #FFFFFF or #A0A0A0
Size: consistent across the set
