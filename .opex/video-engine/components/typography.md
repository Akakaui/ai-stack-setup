# TYPOGRAPHY COMPONENTS

Last updated: 2025-01-25
Version: 1

## TEXT STYLES

Headline large:
  Font: Montserrat Bold
  Size: 72px
  Color: #FFFFFF
  Line height: 1.1
  Use: Hero text, reel hooks

Headline medium:
  Font: Montserrat Bold
  Size: 48px
  Color: #FFFFFF
  Line height: 1.2
  Use: Section headers, carousel titles

Body large:
  Font: Montserrat Regular
  Size: 32px
  Color: #FFFFFF
  Line height: 1.5
  Use: Main content, explanations

Body medium:
  Font: Montserrat Regular
  Size: 24px
  Color: #FFFFFF
  Line height: 1.5
  Use: Supporting content

Body small:
  Font: Montserrat Regular
  Size: 18px
  Color: #A0A0A0
  Line height: 1.4
  Use: Captions, secondary text

Accent text:
  Font: Montserrat Bold
  Size: 24-48px
  Color: #FF6500
  Use: Key numbers, highlights (ONE per scene max)

## KINETIC TEXT PATTERNS

Typewriter:
  Characters appear one by one
  Speed: 50ms per character
  Use: Building tension, revealing information

Word by word:
  Words appear sequentially
  Speed: 100ms per word
  Use: Emphasis, pacing

Counter:
  Number counts up from 0 to target
  Duration: 1000ms
  Use: Stats, revenue numbers, results

## TEXT PLACEMENT RULES

Reels (9:16):
  Headlines: top 30% of frame
  Body: middle 40%
  CTA: bottom 20%
  Keep 10% margins on all sides

YouTube (16:9):
  Headlines: top 25%
  Body: middle 50%
  Lower thirds: bottom 15%
  Keep 10% margins on all sides
