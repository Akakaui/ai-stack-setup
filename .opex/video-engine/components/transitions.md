# TRANSITIONS

Last updated: 2025-01-25
Version: 1

## SCENE TRANSITIONS

Cut:
  Duration: 0ms
  Type: instant
  Use: fast pacing, urgency

Fade:
  Duration: 300ms
  Type: opacity 0 → 1
  Use: scene changes, gentle pacing

Slide left:
  Duration: 400ms
  Type: current exits left, next enters from right
  Use: progression, moving forward

Slide up:
  Duration: 400ms
  Type: current exits up, next enters from bottom
  Use: revealing information, building

Zoom in:
  Duration: 500ms
  Type: current scales up and fades, next scales from small
  Use: emphasis, diving deeper

Zoom out:
  Duration: 500ms
  Type: current scales down, next scales from large
  Use: pulling back, showing context

## TRANSITION RULES

- Match transition speed to content pacing
- Fast content = fast transitions (cut, slide)
- Thoughtful content = slow transitions (fade, zoom)
- Never use more than 2 transition types per video
- Consistency > variety
