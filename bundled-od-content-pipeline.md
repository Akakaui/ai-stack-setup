# Content Pipeline

This skill integrates with the agent skill at `~/.agents/skills/content-pipeline/`.

## Open Design Usage

- Design projects (landing pages, prototypes, UI) are created in Open Design
- Use the design workspace to prototype layouts
- Then extract and enhance with real assets via the agent skill
- Save reusable design systems for branding

## Workflow

1. **Prototype** in Open Design (get the layout right)
2. **Export** the design structure
3. **Enhance** with real assets via agent skill (replace placeholders with real logos, icons, illustrations)
4. **Deliver** clean HTML/CSS with all real assets embedded

## Asset Rules (same as agent skill)

- No Lucide, Feather, Heroicons
- No AI-generated full-page images as design
- Use Hugeicons, Phosphor, unDraw, Humaaans
- Fetch real logos from SimpleIcons or brand sites
- Ask user before substituting assets
